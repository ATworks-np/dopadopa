# Definition of Done / 受け入れ基準

## 各チケット共通

- [ ] 受け入れ条件がすべて満たされ、チケットのチェックボックスが `[x]` になっている
- [ ] 変更内容、影響、関連FR/ON/ACが追跡できる
- [ ] 実行したテストと結果（成功/失敗）が `## 検証記録` に記載されている
- [ ] 個人データ・入力欄/機密UIの原文が不要なログ/クラウドに保存されていない
- [ ] 不明なUI情報が推測値で補完されていない
- [ ] failure/permission denied/timeoutの扱いが検証されている
- [ ] 該当する場合、実データとサンプルの区別がつく
- [ ] レビュー済み、PR/コミットIDまたは成果物へのパスが記載されている

## MVP (P0) の受入条件

| AC | 合格根拠 |
|---|---|
| AC-01 | YouTubeだけが選択可能。内部はapp_idで汎用管理。 |
| AC-02 | 実機のYouTubeイベントをsession_id/event_id付きで保存し、欠損を表示。 |
| AC-03 | 実機でクリック文言を少なくとも1例取得。取れなければ未達として報告。 |
| AC-04 | GeminiがToolでセッションを調査し、話題/転換点の仮説を生成。 |
| AC-05 | UIに根拠event_idと「不明」を示せる。 |
| AC-06 | 本人による評価・訂正が保存される。 |
| AC-07 | MVP対象外（2026-10-11ユーザー指示）。既存Webデモは参考成果。 |

## 禁止する「見かけ上の成功」

- 架空ログをAndroidの実機収集と表示する
- YouTubeで取得不能な動画タイトルを手作業で埋めて取得成功扱いする
- Geminiが存在しない `event_id` を根拠として挙げる
- 「Shorts利用」だけで「後悔あり」「無意識」を断定する
- メール、メッセージ、認証情報を含む原文をCloud Runに転送する

## チケット検証記録の記載例

```text
## 検証記録
- 2026-10-11 / Android Emulator (Android 15): `./gradlew testDebugUnitTest` → PASS
- 2026-10-11 / Pixel実機: CLICKが3件、文字列取得1件、missing 2件。実ログ保存先: artifacts/redacted-click-events.json
- レビュー: PR #12 / スクリーンショット: artifacts/collector.png
```

検証ができない場合は推測で埋めず、未検証・ブロッカーとして記録する。
