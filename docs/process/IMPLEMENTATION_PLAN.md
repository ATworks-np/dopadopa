## 検証シナリオ（最低3本）

- **学習 → Shorts**：技術系クリックからShortsへ移る。話題の変化候補とevent_idを表示。意図的休憩の可能性を保持。
- **学習継続**：技術動画が続く場合、誤って「脱線」と決めつけない。
- **観測不能**：テキストmissingが大半の場合はunknownを返し、根拠が足りないことを明示。

## スコープ制限

- シナリオは**デモ用サンプル**と実機記録を区別する。
- 「取得可能なYouTubeクリック文字列の分析」がP0。「可視テキストの表示時間」はP1。
- 実データが取得できないとき、サンプルを使ってAI分析を作動させることは可能だが**実機収集の受入達成とはしない**。
- 強制遮断・全アプリ監視・強化学習は今回のP0では行わない。
