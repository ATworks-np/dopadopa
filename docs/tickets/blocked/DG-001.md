# DG-001: YouTube実機イベント取得スパイク

## 目的
実機でYouTubeクリックイベントとタイトル/ラベルの取得可否を確認し、MVPの最大リスクを最初に確定する。

## 成果物
- 試験用Android AccessibilityService
- 対象画面ごとの匿名化検証ログ
- 取得可能/不可の記録表

## 作業手順
1. AndroidテストアプリにAccessibilityServiceを仮実装し、利用者が手動で有効化できるようにする。
2. YouTubeのホーム、検索結果、動画詳細、Shortsでクリック操作を発生させ、eventType/package/source/text/contentDescription/親子ノードの取得可否を観測する。
3. パスワード/検索入力欄/私的コンテンツをログ対象から除外し、画面種別別に取得率・欠損を記録する。
4. 取得できた文字列と実際の画面表示を照合し、App Adapterで扱う必要があるケースを列挙する。

## 受け入れ条件
- [ ] 少なくとも1画面でクリックイベントの取得を確認する
- [ ] クリック文言を実機で1例以上確認する（できなければ未達と記録する）
- [ ] 取得不能のケースをmissingで記録し、架空データを混ぜない
