# DG-016: 提出用README・説明資料・デモ動画の準備

## 目的
行動理解エージェントの価値と動作を短時間で伝える提出素材を作る。

## 成果物
- リポジトリREADME
- アーキテクチャ説明
- 短いデモ動画と提出チェックリスト

## 作業手順
1. ユーザーの課題→YouTubeクリック収集→Gemini Tool Calling→根拠付き推定→本人訂正の流れを台本化する。
2. 実機ログの可否とsample/realを画面・説明に記載する。
3. デプロイ先・環境変数・再現手順・既知の制約をREADMEへまとめる。
4. 提出要項・URL・動画尺・締切を公式ページで再確認する。

## 受け入れ条件
- [ ] 第三者がREADMEからWebデモを起動/確認できる
- [ ] 誇大な後悔判定や実ログ取得成功の主張がない
- [ ] 提出要件を公式情報と照合した
