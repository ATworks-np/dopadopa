# DG-202: 複数アプリ選択の解禁

## 目的
汎用スキーマを維持したまま監視対象アプリの選択を拡張する。

## 成果物
- App Adapter追加
- 複数アプリ選択UI

## 作業手順
1. 新しい対象アプリのデータ取得可能性・同意の範囲を検証する。
2. 対応可否を設定データで制御する。
3. 未知UIの扱いと安全テストを行う。

## 受け入れ条件
- [ ] YouTubeの既存動作が維持される
- [ ] 未対応アプリを勝手に監視しない
- [ ] 対象ごとの同意が管理できる

## 注意 / 対象外
