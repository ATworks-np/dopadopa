# DG-101: コンテンツ表示時間（露出）の推定

## 目的
文字列が画面上に表示された推定秒数を算出し、クリック以外の関心推定材料を増やす。

## 成果物
- ContentExposureTracker
- 可視領域・duration・quality_flag

## 作業手順
1. 表示開始/非表示/画面OFFを識別する。
2. 同一表示要素を連続追跡し、可視範囲の信頼度を記録する。
3. 読了/注視と混同しない表示を作る。

## 受け入れ条件
- [ ] 表示露出時間がセッションに紐づく
- [ ] 表示できない要素は不明扱い
- [ ] 視線・再生時間と明確に区別する
