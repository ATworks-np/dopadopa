# DG-307: 本人選択履歴と再起動・撤回の状態管理

## 目的
要件定義v0.3の自動監視・本人承認による介入を実現する。正本: requirements/REQUIREMENTS_v0.3.md。

## 成果物
- continue/correct/unknown/pause/stopと期限/解除を区別する
- 本人の操作だけを保存し未回答と自動判定を混同しない
- アカウント変更・世代変更・再起動・サービス再接続を検証する

## 作業手順
1. continue/correct/unknown/pause/stopと期限/解除を区別する
2. 本人の操作だけを保存し未回答と自動判定を混同しない
3. アカウント変更・世代変更・再起動・サービス再接続を検証する

## 受け入れ条件
- [ ] 本人回答と実行履歴が再表示でき観測は不変
- [ ] 遅延応答/旧所有者/旧同意が履歴と提案を復活させない
- [ ] 再起動時の予算/通知cooldown/休止期限を復元する
