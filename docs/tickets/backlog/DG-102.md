# DG-102: やさしい通知・続行確認UI

## 目的
行動理解に基づく弱い介入を試作する。

## 成果物
- 通知UI・任意の続行確認
- ユーザーの拒否/停止操作

## 作業手順
1. 通知可能条件とクールダウンを定義する。
2. 利用目的の確認に留め、強制遮断しない。
3. 通知を止める/無効化する選択肢を実装する。

## 受け入れ条件
- [ ] 強制ブロックを行わない
- [ ] 連続通知が発生しない
- [ ] ユーザーが解除/無効化できる
