# DG-008: 機密除外・同意管理・安全な同期

## 目的
許可されたYouTubeの非機密データだけをCloud Runへ送る。

## 成果物
- PrivacyFilter/ConsentGate
- 同期キュー
- 同意撤回/削除フロー

## 作業手順
1. イベント生成時に入力欄・パスワード・認証・メッセージ本文のフィルタを適用する。
2. ユーザーによるクラウド送信同意の状態をチェックして同期する。
3. TLS/認証・リトライ・重複排除・上限付きバッチを実装する。
4. 同意撤回後の送信停止と既存データ削除導線を実装/確認する。

## 受け入れ条件
- [ ] 未同意のイベントはクラウドに送信されない
- [ ] redactedデータは原文を保持しない
- [ ] 通信失敗でYouTube利用やローカル収集を止めない
