# DG-005: UsageStatsによるYouTubeセッション収集

## 目的
YouTubeの起動・離脱・利用経過をsession_id付きで記録する。

## 成果物
- UsageStats/UsageEventsセッション収集
- 画面ON/OFF・切替によるセッション終端処理
- 匿名化動作ログ

## 作業手順
1. 利用状況へのアクセス許可を説明してOS設定へ導く。
2. 対象packageに限って前面化/離脱イベントを追跡する。
3. 連続イベントをセッションへ統合し、画面OFF・再起動・プロセス再開を扱う。
4. Roomへ保存しUIでセッション一覧を確認する。

## 受け入れ条件
- [ ] YouTubeの利用開始/終了が記録される
- [ ] session_id・時間が保持される
- [ ] 権限なし・端末再起動時にデータを捏造しない
