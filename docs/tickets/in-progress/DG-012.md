# DG-012: Android分析結果画面・根拠イベント閲覧

## 目的
ユーザーがGeminiの推定を操作証拠と照合できる画面を作る。

## 成果物
- 分析タイムラインUI
- 根拠イベントの一覧/ハイライト
- 分析失敗/不足の状態表示

## 作業手順
1. セッション一覧から解析結果へ遷移できる画面を実装する。
2. 時刻・話題・推定意図・転換点の候補を表示する。
3. 根拠イベントIDをタップすると対象イベントが見えるようにする。
4. 仮説/不明/実測の違いをラベルで示す。

## 受け入れ条件
- [ ] 結果からevent_idの根拠を辿れる
- [ ] 不確実性を確認できる
- [ ] 分析中/失敗時に利用操作を邪魔しない
