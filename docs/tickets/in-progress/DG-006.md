# DG-006: Accessibilityクリック収集とYouTube App Adapter

## 目的
YouTube操作のCLICK/SCROLL/WINDOW_CHANGEとクリック文言を取得可能な範囲で記録する。

## 成果物
- AccessibilityCollector
- YouTubeAdapter
- text_status/source/observability対応
- 匿名化ログ

## 作業手順
1. 監視対象packageをconfigで許可リスト化し、他アプリでは収集しない。
2. TYPE_VIEW_CLICKED/SCROLLED/WINDOW_CONTENT_CHANGEDを軽量に取得し非同期キューへ渡す。
3. source.text/contentDescriptionを確認し、必要な場合は子/親ノードから文言を抽出する。
4. editable/password/機密UIは除外する。
5. 文字列が取れない時はtext=null,text_status=missingとし、source/observabilityを記録する。

## 受け入れ条件
- [ ] YouTubeイベントに安定したevent_idを付けられる
- [ ] 直接取得・文脈推定・欠損を区別できる
- [ ] 入力欄や機密情報を保管/送信しない

## 検証記録
- 2026-10-11: AccessibilityServiceとYouTubeAdapter、missing/redacted・直接/文脈区別・同意撤回競合防止をスパイク実装。実機ログなし。DG-001/DG-004実機待ちのため、依存未達での作業はコード準備のみ。
