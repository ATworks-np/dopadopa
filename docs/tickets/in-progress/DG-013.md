# DG-013: ユーザー確認・訂正とフィードバック保存

## 目的
本人が推定を評価/訂正し、その結果を観測事実と独立に記録する。

## 成果物
- 3択フィードバックUI
- 任意の訂正入力
- Feedback API / 保存テスト

## 作業手順
1. 分析結果に「合っている」「違う」「分からない」の3択を設ける。
2. 違う場合、本人が利用意図を任意で訂正できる。
3. APIへ本人操作からのみフィードバックを保存する。
4. 元のイベントを改変せず、analysis_idと訂正履歴を関連付ける。

## 受け入れ条件
- [ ] 本人の回答が保存・再表示できる
- [ ] 未回答と「合っている」を区別する
- [ ] Agentが本人の代わりに訂正を作成できない
