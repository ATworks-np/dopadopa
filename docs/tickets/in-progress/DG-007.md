# DG-007: イベント正規化・タイムライン統合

## 目的
UsageStatsとAccessibilityのイベントをセッション内で順序付けし、後段Toolが検索できるようにする。

## 成果物
- EventNormalizer/TimelineRepository
- 重複抑止・時刻処理
- Timelineテスト

## 作業手順
1. 複数Collectorからのイベントを共通InteractionEventへ変換する。
2. イベント時刻順・同時刻順序のルールを定義する。
3. 連続SCROLLを必要に応じて集約しつつクリックイベントを保持する。
4. YouTubeセッションとイベントを関連付け、欠損と終了条件を検証する。

## 受け入れ条件
- [ ] 時系列が安定して再現できる
- [ ] SCROLLが高頻度でもメインスレッドが止まらない
- [ ] 例外・不正時刻・重複をテスト済み

## 検証記録
- 2026-10-11: 未実装。Collectorの実機受入待ちのため、Roomに基づく正規化コード準備に限定して並行着手。

- 実装: 共通イベント、timestamp/eventId順、sessionAtによる遅延イベント照合、cursorの巻戻り禁止、500ms SCROLL抑止、7日保持。最終Androidビルド/単体14件/実行5件PASS。実機統合は未検証。
